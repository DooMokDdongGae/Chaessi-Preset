## 와이드·롱 이미지 크기

작업대 아래 **이미지 크기**에서 **보통** 또는 **크게**를 고릅니다. 각 버튼의 가로 × 세로 픽셀을 확인하고 **이 크기 적용**을 누르세요. 새 와이드·롱 버튼은 V5에서 사용할 수 있는 사용자 지정 치수를 작업대에 등록한 빠른 선택입니다.

| 범주 | 기본 가로 | 와이드 가로 | 기본 세로 | 롱 세로 | 정사각형 |
| --- | --- | --- | --- | --- | --- |
| 보통 | 1216 × 832 | 1344 × 768 | 832 × 1216 | 768 × 1344 | 1024 × 1024 |
| 크게 | 1536 × 1024 | 1664 × 960 | 1024 × 1536 | 960 × 1664 | 1472 × 1472 |

여러 인물과 넓은 배경에는 와이드 가로, 전신을 세로로 담을 공간이 필요할 때는 롱 세로를 써 보세요. 실제 구도는 프롬프트와 생성 결과에 따라 달라집니다. 초기값은 832 × 1216이며 작게·배경화면·직접 입력과 가로·세로 교환도 사용할 수 있습니다. 저장된 프리셋의 치수와 카메라·프롬프트는 자동으로 바뀌지 않습니다. 크게는 픽셀 수가 많아 비용이 달라질 수 있으니 생성 전 예상치를 확인하세요. ## 메타데이터 리더 설치와 연결

Windows x64용 [리더 v1.0.0 Release](https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/releases/tag/v1.0.0)에서 설치판과 Chrome 확장 ZIP을 받아 같은 Release의 `SHA256SUMS.txt`와 대조하세요. Preset은 같은 PC에서 v3.8.5 Portable을 사용합니다. 두 앱 모두 2026-11-23 수정본을 선택하세요.

### 처음 한 번 설정하기

1. `Chaessi-Metadata-Reader-Setup-x64.exe`를 설치하고 시작 메뉴에서 리더를 여세요.
2. `Chaessi-Metadata-Reader-Chrome-Extension.zip`을 계속 보관할 폴더에 풉니다. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `manifest.json`이 들어 있는 폴더를 고르세요.
3. 리더의 **Chrome 연결 설정 → 연결 키 복사**를 누르세요. 같은 Chrome 프로필에서 확장의 **리더의 연결 키**에 붙여 넣고 **최초 연결 저장**과 **NovelAI Inspect 접근 허용**을 누르세요.

[리더 설치·최초 연결 안내](https://github.com/DooMokDdongGae/Chaessi-Metadata-Reader/blob/main/README.ko.md#ai-setup)

### 문구를 원하는 칸으로 보내기

1. Chrome의 NovelAI Inspect에서 이미지를 선택하고 리더의 **NovelAI Inspect 가져오기**를 누르세요. 글을 편집하고 원하는 부분을 선택해 **선택 문구 담기**를 누릅니다.
2. 다운로드한 Preset Portable을 직접 여세요. 리더의 보낼 문구 목록에서 **프리셋 연결**을 누르고, **실행 중인 프리셋**에서 버전·실행 경로·PID를 확인해 **이 프리셋 연결**을 누릅니다. 호환되는 폴더형 실행본은 등록한 EXE로 실행을 승인할 수 있습니다.
3. 행마다 받을 베이스·캐릭터의 긍정/제외 칸과 **추가** 또는 **덮어 쓰기**를 정하세요. Medium은 긍정만 받습니다. 기존 칸과 새 번호를 자유롭게 섞거나 큰 번호부터 배치할 수 있습니다. 같은 칸에 여러 문구를 보낼 때에는 **위로/아래로**로 적용 순서를 정하세요.
4. **프리셋으로 보내기**를 한 번 누르고 선택했던 Preset 창의 미리보기를 보세요. 리더 뒤에 있으면 작업 표시줄에서 그 창으로 전환하세요. 캐릭터가 2개일 때 5번으로만 보내면 3·4번은 빈 비활성(Off) 슬롯으로 표시됩니다. 전후 문구와 생성될 번호를 확인해 **초안에 적용**하거나 **취소**하세요. 빈 문구로 덮어쓸 때만 별도 확인이 필요합니다.
5. **리더 전송 되돌리기**는 적용 내용과 새 슬롯을 함께 복구합니다. 보관하려면 작업대 위쪽의 **저장**을 직접 누르세요. 전송에 NovelAI 토큰이나 유료 생성은 필요하지 않습니다.

[받을 창 선택, 재시도 및 되돌리기 안내](https://doomokddonggae.github.io/Chaessi-Preset/v3.8.5/?lang=ko&chapter=reader-transfer)

## v3.8.4 — 부분수정과 아웃페인팅 조작 개선

부분수정 화면에서 휠이나 +/−로 확대·축소합니다. 휠은 커서 위치를 중심으로 확대합니다. 화면 이동을 켜거나 휠 버튼을 누른 채 드래그하세요. 화면에 맞춤과 100%를 선택할 수 있습니다. 확대해도 붓과 지우개는 원본 픽셀 좌표에 맞고 Undo/Redo를 사용할 수 있습니다.

작업대의 부분 수정 또는 이미지 도구의 캔버스 확장 생성에서 **최종 캔버스를 정해 확장**을 누릅니다. 1:1, 9:16, 16:9를 고르거나 너비와 높이를 입력한 뒤 출력 크기를 적용하세요. 원본을 드래그해 옮기고 모서리 손잡이로 크기를 바꿉니다. 새로 채울 빈 영역을 확인하고 이미지와 마스크를 검토한 뒤 생성합니다.

Base와 각 Character 번호별 프롬프트 칸이 프리셋 목록의 표시 범위·전체 보기·스크롤 위치·정렬 상태를 독립적으로 기억합니다. 프리셋을 적용하거나 창을 다시 열면 해당 칸의 마지막 위치가 복원됩니다. **더 보기**로 50개씩 늘리거나 **전체 보기**로 조건에 맞는 항목을 모두 표시하세요. 검색·분류·정렬 변경 시에는 해당 칸의 스크롤이 처음으로 이동합니다. 앱을 다시 실행하면 각 칸은 50개 표시와 맨 위에서 시작합니다.

## 2026-10-28 Wildcard 기능 추가

Wildcard 관리에서 무작위(Random) 또는 순차(Sequential)를 선택할 수 있습니다. 순차는 등록 순서를 반복하며 다음 후보를 표시합니다. 생성과 History 저장이 성공한 뒤 한 번 진행하고, Sample·미리보기·취소·실패는 순번을 소비하지 않습니다. 재시작 후에도 순번을 유지하며 **처음부터**로 초기화할 수 있습니다. 기존 Wildcard는 계속 Random입니다. ## v3.8.2 절대 카메라

v3.7.0을 바탕으로 카메라를 새로 구성했습니다. v3.8.0/3.8.1처럼 원본 방향을 확인한 뒤 상대 이동과 위치별 보정을 적용하는 방식에서, 정면 0°를 기준으로 목표 시점을 지정하는 방식으로 바뀌었습니다.

앱을 실행하면 카메라는 OFF입니다. **새 카메라**를 누르면 ON·정면 0°·상하 0°·상반신·강도 1로 시작합니다. 구체를 가로로 움직여 방향을, 세로로 움직여 상하 시점을 고릅니다. 샷 크기와 높이·팬·틸트·롤은 별도로 조절합니다.

축별 강도는 문구의 강조 정도이며 1은 기본값입니다. 수동 문구는 해당 행의 자동 버튼을 누를 때까지 유지됩니다. 카메라 문구는 생성에 사용할 Base 앞에 추가되며 편집 중인 Base 원문, Character 문구와 Position은 보존됩니다.

선택하면 생성용 Base에서 인식된 독립 카메라 태그를 제외할 수 있습니다. 강조된 단일 태그도 해당할 수 있지만 여러 태그를 함께 묶은 표현과 Character 태그는 남습니다. 알려진 충돌이 남으면 최종 문구 확인에서 별도 확인이 필요합니다. OFF로 바꾸면 일반 생성으로 돌아갑니다.

이미지나 History에서 새 카메라를 시작하면 정면 0°의 T2I로 시작합니다. 저장된 v3.8.2 카메라 작업을 직접 재개하면 저장한 각도·문구를 복원합니다. 앱 재시작 후 자동으로 재개하지 않으며 입력 이미지와 마스크는 카메라 작업에 저장하지 않습니다. I2I/Inpaint로 작업할 때는 따로 준비하세요.

![v3.8.2](assets/manuals/ko/camera-absolute.png)

카메라 설정은 이미지 생성 모델에 구도와 시점에 관한 지시를 전달합니다. 실제 결과는 프롬프트와 모델의 해석에 따라 달라집니다. 신규 카메라의 실제 NovelAI 이미지 품질은 아직 검증하지 않았습니다.

정확한 3D 회전, 좌우 구별, 동일 인물·포즈·배경 유지는 보장하지 않습니다. 좌우 설정이 같은 문구를 만들 수 있고 높이·팬·틸트 표현은 실험적입니다. 자유 문장의 모든 의미 충돌을 자동으로 찾을 수 없으므로 최종 문구를 읽어 보세요.

## 생성 설정과 데이터 보관

High에서는 V5 설정을 조절할 수 있습니다. Medium은 정해진 설정을 사용하며 직접 입력한 Base·Character 제외 프롬프트를 생성에 적용하지 않습니다. 입력한 문구는 보관하므로 High로 돌아가 다시 사용할 수 있습니다.

프리셋, History 이미지·조건, 카메라 작업은 기본적으로 `%APPDATA%\Chaessi Preset`에 저장됩니다. 사용자 지정 경로를 쓰는 경우 실제 저장 폴더를 확인하세요. 업데이트 전 앱을 종료하고 폴더 전체를 백업합니다.

저장한 NovelAI 토큰은 운영체제의 보호 기능을 이용해 암호화합니다. 생성이나 서버 이미지 도구를 실행하면 필요한 이미지·문구·설정을 NovelAI로 전송합니다. Canvas와 Pixel Snap, 저장된 자료 열람과 앱 내 도움말은 로컬에서 사용할 수 있습니다. 선택 사항인 MCP 연결로 저장된 프리셋과 History를 읽을 수도 있습니다.

## 시작·업데이트·백업

1. [공식 배포 목록](https://github.com/DooMokDdongGae/Chaessi-Preset/releases)에서 Windows x64 Portable EXE와 `Chaessi-Preset-v3.8.5-x64.exe.sha256`를 받습니다.
2. EXE를 실행하고 언어를 고릅니다. Portable 실행에는 별도 Node.js 설치가 필요 없습니다. 온라인 생성에는 본인의 NovelAI 계정·토큰과 사용 권한이 필요합니다. 설정의 NovelAI 연결에서 본인 토큰을 입력하고 저장한 뒤 연결 상태를 확인합니다. 토큰은 비밀번호처럼 다루고 공유하지 마세요.
3. 프리셋을 선택하거나 글을 쓰고 High/Medium·크기·비용을 확인해 한 장을 생성합니다. 최근 결과나 History에서 카메라 또는 이미지 도구로 이어갑니다. 앱 정보 → 도움말 센터에서 실제 조작을 확인하세요.
4. 업데이트 전 필요한 편집을 저장하고 앱을 종료한 뒤 실제 데이터 폴더 전체를 별도 백업합니다. 데이터는 유지하고 EXE를 교체합니다. 되돌릴 때는 이전 EXE와 그 버전에 맞는 백업을 함께 사용합니다.

기존 프리셋·분류·Wildcard·History를 강제로 일괄 변환하지 않습니다. V4.5 자료는 읽기·편집·저장할 수 있지만 **신규 V4.5 생성은 지원하지 않으므로 V5로 명시적으로 전환**해야 합니다. 구버전이 새 카메라·구도 기록을 모두 이해한다고 가정하지 마세요. 자동 업데이트와 종료 후 미저장 편집 자동 복구는 제공하지 않습니다.

## 비용과 한계

앱 사용과 NovelAI 이용료는 별개입니다. 서버 요청에는 설정과 계정에 따라 Anlas 또는 V5 Stamina가 사용될 수 있습니다. 표시된 비용은 예상값이며 큰 이미지나 작은 인페인트 마스크가 항상 무료는 아닙니다. 실패한 유료 요청은 자동 재시도하지 않습니다.

Custom 크기는 64의 배수·총 3,145,728픽셀 이하이고 자동 반올림하지 않습니다. Wallpaper Square는 없습니다. 구도 편집은 2D 이미지 배치이며 3D 복원·다중 레이어·원근 편집기가 아닙니다. Pixel Snap은 기존 격자 정돈이며 일반 그림을 새로운 픽셀아트로 창작하지 않습니다. 인원수·배경 연결·표정·마커 위치·자동 격자 추천의 정확도는 보장하지 않습니다.

V5 Precise Reference, Vibe Transfer, ControlNet, 일반 생성용 V5 Curated 선택, 영상·다중 배치 생성은 지원하지 않습니다. 현재 배포 대상은 Windows x64이며 macOS/Linux 배포·코드 서명·자동 업데이트는 제공하지 않습니다. 미서명 EXE의 보안 경고가 나타나면 공식 출처와 체크섬을 확인하고 보안 기능을 일괄 해제하지 마세요.

공개용 작품은 원본과 별도 사본으로 보관하세요. PNG의 일반 메타데이터뿐 아니라 알파 채널에 숨겨진 생성 정보도 확인해야 합니다. 토큰·개인 History·원본 프롬프트·전체 데이터 폴더를 공유하지 마세요.
