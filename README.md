**A local workbench for reusable prompts, characters and image workflows.**

**プロンプトと作品を再利用し、生成と編集をつなぐローカル作業台。**

![User artwork workflow](assets/manuals/examples/workflow.webp)

Presets → V5 Full High/Medium → Camera and manual prompt editing → Image tools → History → Reuse.

The creator controls prompts and revisions. Camera controls select weighted text expressions; they do not guarantee fixed poses or reconstruct a physical 3D scene.
