# v3.7.0 릴리스 검증 기록

검증일: 2026-10-20. Windows x64 Portable 정식 후보. 개인 프로필 대신 격리한 합성 데이터를 사용했다. 원격 공개 다운로드 검증 결과는 발행 후 별도 기록한다.

## 기준 및 변경

PUBLIC 기존 main `1c8c23e2f57e4e694e4b41afc523ca9b99b0a5fa` 이력 위에 공개 제품 파일만 선별했다. 개발 기준 커밋은 `44e5007d24f919e639d8be18f5a53ac6ef14f11a`이다. 개발 저장소의 이력을 PUBLIC으로 합치지 않았다. 기존 태그·Release·v3.6.0 릴리스 문서는 변경하지 않는다.

구도 넓히기, 기존 둥근 붓 전달, 로컬 Pixel Snap, 공식형 해상도 선택, 35장 3개 언어 도움말을 포함한다. 기존 API 계약에는 실질 변경이 없다. 이 승격 과정의 제품 수정은 이미지 처리 History의 버전을 package.json 기준으로 맞추는 변경이다. Electron은 42.11.16, electron-builder는 26.17.0으로 보안 수정판을 적용했다. 테스트용 합성 토큰은 실제 자격 증명과 구별되도록 코드에서 조합하며 유출 차단 테스트는 유지한다.

업데이트 전 데이터의 모든 파일 해시를 보존했고, 의도적인 Save 후에는 해당 프리셋 JSON 하나만 변경됐다. 별도 원본 백업은 끝까지 불변이었다. 기존 EXE가 업데이트 전 복사본을 정상적으로 여는 것도 확인했다. 업데이트 후 새 데이터 폴더를 구버전으로 직접 여는 역호환성을 보장하지 않는다. 롤백은 이전 EXE와 업데이트 전 백업을 함께 사용하는 문서 지침을 따른다. 추가 롤백 전용 실행은 수행하지 않았다.

History 복원 비교는 브라우저 Canvas 정규화된 원본·마스크 및 배치에 대해 정확히 일치한다. PNG 파일 인코딩 바이트와 픽셀 비교를 혼동하지 않는다. 원본 브라우저 왕복의 미세한 경계 반올림은 자산 출처 기록에 명시되어 있다.

## API·보안·라이선스

이 릴리스 작업의 새 유료 호출은 **0건, 0 Anlas**다. 직전 검증의 실제 요청 7건(관측 87 Anlas: High/Medium, Large/Wallpaper/Custom, 구도·캐릭터 추가·붓 후속 수정)을 검토하고 계약이 유지됨을 대조했다. 원본 영수증·계정 잔액·개발 연구 문서는 공개하지 않는다. mock UI 시험은 실제 서버 품질 재검증으로 주장하지 않는다.

최종 npm production audit는 0건이다. 전체 개발 의존성에는 sprintf-js→roarr→global-agent→빌드 도구 경로의 moderate 8건이 남는다. high/critical은 0건이며 해당 빌드 의존성은 EXE 내부 앱 의존성에 포함되지 않는다. Electron은 devDependency여도 실제 배포 런타임이므로 별도로 수정판 42.11.16을 적용하고 실제 실행 버전을 확인했다. 강제 구버전 다운그레이드로 경고를 숨기지 않았다. 알려진 문제가 전혀 없다는 의미는 아니다.

MIT, THIRD_PARTY_NOTICES 및 기존 의존 라이선스를 유지했다. NAIA/GPL 코드를 복사하거나 번역하지 않았다. 외부 도서관 이미지와 파생본은 공개 트리·패키지에 포함하지 않았다. 새 온실 예제와 독립 픽셀 원본만 새 시각 자료로 사용한다.

## 검증의 한계

강제 DPR 시험은 실제 Windows 혼합 DPI 모니터 간 이동 시험이 아니다. 일반 사용자 사용성 연구는 수행하지 않았다. 공식 Pixel Snap과 알고리즘·출력이 동일하다는 검증은 없으며 독립 로컬 구현으로 설명한다. 모델의 경계 연결·인물 수·위치·자동 격자 정확도를 보장하지 않는다. V4.5는 과거 자료 읽기·편집·저장만 지원하며 신규 생성은 지원하지 않는다.
