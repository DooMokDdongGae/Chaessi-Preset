# Updating to v3.6.0 / 업데이트 / 更新

## 한국어

1. 편집 중 글을 프리셋으로 저장하고 앱을 종료합니다.
2. Windows의 `%APPDATA%\Chaessi Preset`을 별도로 복사합니다. `data/`에는 전체/Base/Character/의상 프리셋·분류·Wildcard·History가 있습니다. 사용자 지정 실행이라면 실제 데이터 폴더를 확인하세요.
3. 새 portable EXE로 교체해 실행합니다. 사용자 데이터 폴더를 지우거나 EXE 내부로 옮기지 마세요.
4. 기존 프리셋·Wildcard·History와 언어를 확인합니다. V4.5 자료는 읽기·편집·저장이 가능하며 생성 전 V5를 선택합니다. 새 저장에는 v3 프리셋 형식이 쓰일 수 있습니다.
5. 이전 버전으로 돌아가려면 종료 후 백업 데이터와 이전 EXE를 함께 사용합니다. 구버전이 새 저장 내용을 모두 읽는다고 가정하지 마세요.

데이터 전체를 강제로 변환하지 않습니다. 저장하지 않은 편집은 종료 후 자동 복구되지 않습니다. 토큰 저장소는 PC의 암호화 기능에 연결되므로 다른 PC에서 복호화되지 않을 수 있습니다. 개인 백업·토큰을 공개하지 마세요.

## English

Save work and close the app. Back up `%APPDATA%\Chaessi Preset` (or your customized data root). `data/` holds full/Base/Character/outfit presets, categories, Wildcards and History. Replace the portable EXE, keeping the external data intact. Check your library and language. V4.5 remains readable/editable/savable; choose V5 to generate. New saves may use schema v3.

For rollback, close the app and use the backup with the old EXE. Do not assume old versions read every new save. There is no forced whole-library conversion or recovery of unsaved edits after quitting. Encrypted tokens can be tied to this PC; never publish backups or credentials.

## 日本語

作業を保存して終了し `%APPDATA%\Chaessi Preset`（独自設定なら実際のデータ先）をバックアップします。`data/` は全体/Base/Character/衣装・分類・Wildcard・履歴です。データ先を残して portable EXE を交換し、旧ライブラリと言語を確認します。V4.5 は読込/編集/保存を保ち、生成は V5 です。新規保存は v3 形式になる場合があります。

戻す場合は終了後に旧 EXE とバックアップを一緒に使います。旧版が新形式をすべて読めるとは限りません。一括強制変換や終了後の未保存編集復元はありません。暗号化トークンは PC に結び付く場合があります。個人バックアップや資格情報を公開しないでください。
