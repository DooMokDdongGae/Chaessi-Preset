# Prompt Set Generator 연출 지식 감사 — 2026-09-08

## 결론

**A. 상당한 수준의 이미지 연출 노하우가 system prompt에 포함되어 있다.**
특히 가시성에서 역산하는 구도, 화면 내 인물 면적, 시점과 외형의 모순 방지,
고정 인물 설정과 장면별 상태 분리가 구체적이다. 단, 좋은 이미지가 실제로 더 많이
생성된다는 실험 결과는 이번 감사로 입증하지 않았다. 완성된 화보 감독 체계라고
보기에는 샷 리듬·정적/동적 비율·조명 전개·샷 유사도 관리가 부족하다.

- 조사 원본: 사용자가 제공한 Prompt Set Generator ZIP의 `prompt_set_core.py`
- 조사 당시 원본 SHA-256: `EB8D3E9B010565FA3AB7016298BDAAC6C4D9A2552D7C8FA9F8E7287BBFE55D7D`
- 배포 정책: 라이선스를 확인할 수 없는 원본 코드 사본은 공개 소스와 앱 패키지에 포함하지 않는다.
- 주요 상수: `SYSTEM_PROMPT` 31–291행, `DEFAULT_CREATIVE_PREFIX` 294행.
- 아래 O 항목은 원본에서 확인한 지식이다. N 항목은 이번 감사에서 제안한 미래 확장이다.

**존재 범위와 부재를 구분한다.**

- 배경/인물 관계와 전경/후경: 위치·깊이·접촉·가림 지시는 있다. 전경/중경/후경의 3단 구성을 필수화하는 규칙은 없다.
- 시선 유도: focal subject·focal emphasis와 인물 시선/방향 규칙은 있다. leading lines 등 구체적인 시선 유도 체계는 없다.
- 샷 중복: 의미 있는 차이를 요구하지만 샷 유사도 점수나 중복 검출 알고리즘은 없다.
- 정적/동적 장면 배분, 클로즈업/미디엄/전신 비율, 화보 리듬: 명시적 배분 규칙은 없다.
- 표정: 캐릭터 scene_prompt에 구체화하고 시점과 맞추라는 지시는 있다. 샷마다 감정 변화를 계획하라는 별도 규칙은 없다.
- 조명·시간·날씨: global prompt의 필드 책임으로 등장한다. 광원 방향/색 대비/시간대 변화 전략은 없다.
- 서사: 독립/연속 구분과 다음 행동·상태 계승은 있다. 도입–전개–클라이맥스 등의 서사 설계는 없다.
- 분위기: 눈에 보이는 조건으로 표현하게 한다. supplement에 추상적인 분위기 해석·스토리 의미를 넣는 것을 금지한다.

**Prompt weighting:** SYSTEM_PROMPT에는 가중치 문법·추천 수치·강조 강도 조정 노하우가 없다.
프리셋/원문 문자열에 가중치가 있다고 해서 연출 지식으로 확인한 것은 아니다.
원본 지식은 안전한 결과나 시각 품질을 보장하는 모델 검증기가 아니며 LLM에 대한 지시다.

## 새로 제안하는 규칙 — N (원본에 있었던 것으로 취급하지 않음)

- N01: 샷별 거리·앵글·동작·표정·광원 표를 만들고 의미 중복 점검.
- N02: 사용자 목적에 따라 정적/동적·와이드/디테일 비율과 순서를 정하는 화보 리듬.
- N03: 저장된 캐릭터·의상 ID를 원본 설정의 권위로 삼고 LLM 임의 재설계 방지.
- N04: 고정 seed와 선택된 wildcard 값을 기록하여 dry-run과 전송의 재현성 확보.
- N05: 대사/품질/negative 충돌 및 모델별 토큰 예산 검토.

향후 Codex Image Director는 O-D03~08, O-P01~05, O-P10을 핵심 설계/검토 단계로
보존하고 N 항목은 별도 확장 버전으로 추가한다. 이 단계에서는 활성 지시문이나
하드코딩된 연출 규칙을 만들지 않았다.
